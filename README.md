# ANIMO Signalisatie — zelfstandige demo

Deze repository bevat een zelfstandige demonstratie van ANIMO Signalisatie voor Belgische horecazaken.

## Veiligheidsgrens
- Geen koppeling met de bestaande ANIMO HACCP-app.
- Geen Supabase-configuratie, klantaccounts of klantgegevens.
- Checklistvoortgang wordt uitsluitend lokaal in de browser bewaard.

## Lokaal testen
Open `index.html` via een lokale webserver of publiceer de repository met GitHub Pages.

## Publiceren met GitHub Pages
1. Open **Settings → Pages**.
2. Kies bij **Build and deployment** de bron **GitHub Actions**.
3. De workflow in `.github/workflows/pages.yml` publiceert de site bij een push naar `main`.

## Belangrijke beperking
Dit is een demonstratie, geen juridisch attest. De wettelijke toepasbaarheid verschilt per activiteit, gebouw, regio en lokale voorwaarden. Controleer altijd de gekoppelde officiële bronnen. Voor de FAVV-affiche, camerabewaking en brandveiligheid moet het officiële model of advies van de bevoegde instantie worden gebruikt.
